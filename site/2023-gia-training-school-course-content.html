2023 GIA Training School Course Content

Homework and Training School Preparation:

The below homework exercises are provided to prepare participants for the school.  The aim is to introduce you to the modeling software that will be utilized.  You are encouraged to begin studying these materials and working with the software as soon as possible.  We anticipate some students will progress farther than others based on experience level, but it is expected that all participants attempt to become familiar with the material.  Each participant should bring a laptop for use during the school.  The below list of homework exercises should be completed on the laptop that the participant will bring to the school.

Exercise 1: Read SELEN4 User Guide and Theory

Participants will utilize open-source GIA modeling software SELEN (a SealEveL EquatioN solver) version 4 during the training school.  Participants should begin working with SELEN4 prior to the school.

Students should start by reading the user guide, it is called User_Manual.pdf and is available HERE.  Students should also read (at least look at) the theory paper introducing SELEN4, it is available HERE.

Exercise 2: Download, Install, and Run SELEN4

After becoming familiar with the user guide and theory, participants should download and install SELEN4, it can be downloaded HERE (same link from Exercise 1). Confirm you are able to run the program by executing the "test run" described in the theory paper from Exercise 1.

Once at the school participants will discuss the outputs in connection with the theory.  Please note that installing tools like gfortran or any graphic tools to visualize the data is left to the participant.  

Exercise 3: Install Python

To complete exercises during the training school, participants will need to have Python running, ideally with Jupyter Notebook (https://jupyter.org). Participants should have at least Python running on their laptop before arriving to the school.

Exercise 4: Review PISM

Participants can learn to use open-source ice sheet modeling software PISM (Parallel Ice Sheet Model) during the training school.  Participants should review the PISM website, available HERE, which includes a well-maintained manual with simple examples.  Participants may also review a rather technical paper on paleo Antarctic Ice Sheet modeling using PISM with parameter sensitivities and climate forcing uncertainties, available HERE.

Exercise 5: Attempt PISM installation

PISM installation can be easy on Ubuntu and MacOS but can be tricky on Windows.  Participants are encouraged to try installing the software (with required dependencies, like PETSc). Installation instructions are available HERE.
