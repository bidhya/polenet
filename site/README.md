# site

The rebuilt static polenet.org website — HTML, CSS and a little JavaScript. No WordPress, no
PHP, no database.

## Two ways to use this folder

**As the deployable output of a generator (how the project runs today).** Every page here is
generated by `scraper/build_site.py`. Editing files in this folder directly works until the next
build, which overwrites them. If the generator is still in use, make content changes at the
source and rebuild.

**As a plain static site (a perfectly valid handover option).** This folder is entirely
self-contained: relative links throughout, one stylesheet, and no build step. Point any static
host at it and it works. If you take this route, you are choosing to retire the generator —
edit the HTML directly and stop running `build_site.py`, because the two modes overwrite each
other. Pick one deliberately.

## External dependencies

The pages are self-contained apart from two things:

- **GLightbox**, loaded from a CDN for the photo gallery, pinned to `glightbox@3.3.1`. The pin is
  deliberate — an unpinned path resolves to whatever is latest, so a future major release could
  break the gallery with no change here.
- **35 YouTube video embeds**, on three field-season pages. They come from the project's own
  channel. Deleting or re-uploading one of those videos breaks the page it appears on, silently.

## To rebuild

```
uv run python scraper/build_site.py
```

Works from a fresh clone — everything the builder reads is committed. `archive/images/` is
gitignored and **not** required; the builder falls back to the committed files in `site/images/`.
Afterwards `git status` should be clean, since the rebuild is byte-identical.

## Live

- **Production:** https://bidhya.github.io/polenet/ — GitHub Pages, deployed from `main`
- **Preview:** https://monumental-dieffenbachia-d72518.netlify.app/ — Netlify, from `dev`

Note that `sitemap.xml` and `robots.txt` contain absolute URLs, generated from the
`SITE_BASE_URL` constant in `scraper/build_site.py`. If the site ever moves to another domain,
change that one line and rebuild; nothing else in these pages depends on the address.
